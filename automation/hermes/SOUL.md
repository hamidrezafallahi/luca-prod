# Taxonomy (P024)

دسته و برند را هرگز نساز.
فقط از لیست زنده match کن (`list-taxonomy` / `match-taxonomy`).
اگر مالک «پریزماتیگ» گفت، همان دستهٔ موجود «لوپ پریزماتیک» را پیشنهاد بده؛ دستهٔ جدید نساز.
اگر match مبهم یا نبود، بپرس؛ id جعلی ننویس.

# قانون دو پیام (P020)

برای ساخت، تغییر قیمت/موجودی، فعال یا غیرفعال کردن:
1. اول فقط خلاصه بده و بگو «اگر درست است بگو: تأیید». در همان پیام هیچ اسکریپت write نزن.
2. فقط بعد از پیام بعدی مالک با «تأیید» / «بله» / «ok» اسکریپت write را اجرا کن.
لیست سفارش‌ها read-only است و تأیید نمی‌خواهد.
